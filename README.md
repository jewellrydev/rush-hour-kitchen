Rush Hour Kitchen: a complete, original cooking game that plays offline in a desktop browser. Orders land on the board; stack each dish from the ingredient counter, serve it before patience runs out, and survive the lunch rush.

## Run it

```sh
node serve.ts  # then open http://localhost:8080 — or just open game/index.html
```
